## 🚀 Проект 1: Стартап CryptoWhale Signals (FinTech)
**Роль:** Инициатор проекта, CEO (разработка концепции и защита)  
**Контекст:** Разработка полного пакета документов для подачи заявки в бизнес-инкубатор РЭУ им. Г.В. Плеханова.  

**Что было сделано:**
- С нуля разработал бизнес-модель (Business Case) и финансовую модель (расчет unit-экономики, точки безубыточности, срока окупаемости).
- Спроектировал организационную структуру команды и дорожную карту развития продукта.
- Подготовил питч-дек и речь для защиты перед экспертной комиссией.

**Результат:** Проект получил высшую оценку от жюри за качество «упаковки» и проработку бизнес-процессов, несмотря на высокие технические риски идеи на этапе Pre-seed.
